# IdVerify — Demo

Demo interactiva del sistema DocVerify (TFM — Detección de Identidades Falsas Generadas con
Inteligencia Artificial). Permite analizar documentos de identidad con tres codificadores
distintos (Patel CNN, EfficientNet-B4, ViT-B/16) y visualizar la máscara de segmentación
superpuesta junto con la probabilidad de falsificación estimada.
